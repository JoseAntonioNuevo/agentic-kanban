# Sesión 4 · 03 — El hilo en el diálogo de editar

## Punto de partida

`GET` y `POST /api/tasks/:taskId/comments` funcionan (02). `TaskFormDialog`
tiene un modo «crear» y un modo «editar» (Sesión 2).

## Objetivo

Ver y añadir comentarios dentro del diálogo de **editar** tarea.

## Contratos que fijas aquí

- `useComments(taskId, userId)` y `useCreateComment(taskId, userId)` con
  `commentsQueryKey(taskId, userId)` en `apps/web/src/hooks/use-comments.ts`.
- `TaskComments` en `apps/web/src/components/task-comments.tsx`.

## Requisitos

- El hilo solo aparece en el modo editar; el diálogo de crear no lleva
  comentarios.
- Botón **Comentar** (`type="button"`) distinto de **Guardar**. Guardar hace el
  `PATCH` de la tarea y nunca crea un comentario; Comentar hace
  `POST /api/tasks/:taskId/comments` con `{ body }`.
- TanStack Query para listar y crear, con `fetch` relativo,
  `credentials: "include"` y el mismo schema Zod que la API. Al crear,
  actualiza o invalida la query del hilo.
- Estado local solo para el texto del comentario nuevo: se vacía al publicar;
  el botón se desactiva si está vacío o enviando; los errores se muestran.
- El texto del comentario se pinta como texto plano (con saltos de línea), sin
  `dangerouslySetInnerHTML`. Autor y fecha en cada fila.
- No copies el board a `useState`. Sin React Router ni React Hook Form; solo
  componentes shadcn que ya existen.

## Fuera de alcance

Menciones, campana, email y realtime de comentarios.
