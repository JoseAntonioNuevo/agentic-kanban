# Sesión 2 · 05 — El tablero en la interfaz

## Punto de partida

La API del tablero funciona (03) y la colección de Postman la ha probado (04).
El dashboard lista los workspaces con sus projects, sin enlaces todavía.

## Objetivo

Un Kanban usable: abrir un project desde el dashboard, ver sus columnas y
tareas en orden, y crear, editar y borrar tareas.

## Contratos que fijas aquí

- `useBoard(projectId, userId)` y `boardQueryKey(projectId, userId)` en
  `apps/web/src/hooks/use-board.ts`.
- `useTaskMutations(projectId, userId)` (crear, editar y borrar) en
  `apps/web/src/hooks/use-task-mutations.ts`. Todas las mutations del tablero
  llevan una `mutationKey` que empieza por `["board", projectId]`: la Sesión 3
  la usa para saber si hay un cambio propio en curso.
- Componentes en `apps/web/src/components/`: `board-screen.tsx` (cabecera con
  el nombre del project y botón de volver), `kanban-board.tsx`,
  `kanban-column.tsx`, `kanban-card.tsx` y `task-form-dialog.tsx`: un solo
  diálogo con modo «crear» y modo «editar». La Sesión 4 añadirá los
  comentarios en el modo editar.

## Requisitos

- Navegación sin router: cada project del dashboard abre su tablero
  (`selectedProjectId` como estado local en `App.tsx`) y hay un botón para
  volver.
- `fetch` relativo a `/api/...` con `credentials: "include"`; las respuestas
  se parsean con los schemas de `@agentic-kanban/schemas`.
- TanStack Query es la única fuente del estado del servidor: no copies el board
  a `useState`. React state solo para lo local (diálogo abierto, texto del
  formulario). Tras cada mutation, actualiza o invalida la query del board.
- Componentes shadcn que ya existen (`card`, `button`, `dialog`, `alert-dialog`
  para confirmar el borrado, `input`, `textarea`, `label`, `badge`). Ningún
  paquete nuevo.
- Estados: cargando, error, columna vacía y project no encontrado (404, con
  botón de volver). Login, logout y el usuario sin workspaces siguen funcionando.

## Fuera de alcance

Mover tareas, drag-and-drop, realtime y comentarios.

4. Tú: revisa el diff (fuente única de verdad, estados, sin `useState` del
